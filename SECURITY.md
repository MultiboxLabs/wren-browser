# Security

Report a security vulnerability in Wren Browser privately, never as a public issue.

Report it on [this repository's Security tab](https://github.com/MultiboxLabs/wren-browser/security/advisories/new). Say which version it affects, from Wren's About window, how to make it happen, and what it lets an attacker do. Multibox Labs replies there, and publishes an advisory once a fixed version is out.

Only the latest version gets fixes.

A vulnerability in Chromium itself, which Wren also has, goes to [Chromium's tracker](https://www.chromium.org/Home/chromium-security/reporting-security-bugs/). Wren takes Chromium's fix in a later version.
