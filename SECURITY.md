# Security

Report a security vulnerability in Wren Browser privately, on [this repository's Security tab](https://github.com/MultiboxLabs/wren-browser/security/advisories/new), never as a public issue.

Say which version it affects, as Wren's About window shows it, how to make it happen, and what it lets an attacker do. Multibox Labs replies there, and publishes an advisory once a fixed version is out.

Only the latest version gets fixes.

Report a vulnerability in Chromium itself, which Wren has too, on [Chromium's tracker](https://www.chromium.org/Home/chromium-security/reporting-security-bugs/). Wren takes Chromium's fix in a later version.
