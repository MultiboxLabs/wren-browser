# Agent Plans

Plans generated by an agent should be stored here.

## Rules

- When uncertain about details, make it a decision in the plan, and ask the user to clarify that.
- Plans starts from 'proposed', 'approved/rejected' and ends with 'completed'.
- Plans should be detailed enough to be executed by another agent without any additional context except for the plan itself and the codebase of the project.
- Plans should be written in markdown.
- Plans should be planned and executed in branches.
- For larger plans, do multiple phases. Each phase should be a separate commit.
